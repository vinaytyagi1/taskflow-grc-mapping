## 1. Logging Configuration Summary
* **AWS CloudTrail:** Multi-region trail (`taskflow-org-trail`) enabled across all AWS accounts (Prod, Staging, Dev).
* **Log Integrity:** CloudTrail Log File Validation (`SHA-256` digest files) enabled; destination S3 bucket has S3 Object Lock (Governance mode) enabled.
* **Centralized Aggregation:** CloudTrail, AWS GuardDuty, and production Kubernetes application logs stream in real time to **Datadog**.
* **Retention Period:** 90 days hot searchable retention in Datadog; 1-year cold archive in encrypted S3 Glacier.
